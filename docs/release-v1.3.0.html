What's new

  • Duplicate mods are merged automatically — jars resolving to the same mod id are combined on next open of the Mods page; the newest install stays enabled, older ones are marked as disabled. Minecraft no longer refuses to start with "Duplicate mods".
  • The mods folder no longer stacks old + new copies after an update — when Cubelight downloads a newer jar of a mod you already have, the older one is disabled automatically.
  • Uninstalling (removing) a modpack now removes every file Cubelight created — the profile folder itself plus mods / saves / screenshots / resourcepacks / shaderpacks are all removed from disk. Settings, accounts and other modpacks carry over.
  • Full About/Update strings translated in all 10 supported languages (fr, de, pt, tr, ru, zh, ja, ar, es) and the long download-in-background toast on the About page.

Upgrading from v1.2.1

Install this setup over your existing copy — settings, accounts and modpacks carry over. Or wait for the in-app update in Settings → About → Updates.
