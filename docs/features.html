What is inside

A complete launcher,
written from scratch.

Everything you need to play — no bloat, no accounts you must link.

📦

Modpacks & Mod Store

Browse, install and update modpacks and individual mods. Cubelight keeps them isolated from your main setup.

☕

Java, handled

Cubelight finds or installs a compatible Java runtime per version automatically. No PATH editing.

🔑

Sign in your way

Microsoft account sign-in for Java Edition owners, plus offline play. No fake auth, no tricks.

🎨

Skins & Screenshots

Skins gallery with in-game preview and a screenshot manager — all inside the launcher.

🌍

Worlds & Backups

Manage worlds, and make backups before experimenting — restoring takes one click.

🔄

In-app updates

A new release? Settings → About → Updates. It downloads and installs itself quietly.

💎

Cubelight identity

Blocky visuals, animated banner scenes (dawn → storm → snow), blue glow — a look of its own.

🛡️

Per-user, no admin

Installs for you without admin rights. Remove any time from Apps & Features.

Your first launch in 4 steps

1️⃣

Install & open

Run CubelightSetup, no admin needed. Cubelight opens straight to the Home screen.

2️⃣

Sign in or play offline

Use a Microsoft account with Java Edition, or just play offline with a local profile.

3️⃣

Pick a version

The whole library — releases, snapshots, old versions. One click to install.

4️⃣

Press Play

The game starts with everything wired up — Java, RAM, window size.
