Everything you need to play.

A complete launcher, written from scratch. No bloat, no telemetry you didn't ask for.

📦

Modpacks & Mod Store

Browse, install and update modpacks and individual mods. Cubelight keeps them isolated from your main setup.

☕

Java, handled

Cubelight finds or installs a compatible Java runtime per version automatically. No PATH editing, no drama.

🔑

Sign in your way

Microsoft account sign-in for Java Edition owners, plus offline play for fun with friends. No fake auth, no tricks.

🎨

Skins & Screenshots

Skins gallery with in-game preview and a screenshot manager — all inside the launcher.

🌍

Worlds & Backups

Manage worlds, and make backups before experimenting — restoring them takes one click.

🔄

In-app updates

New Release? Settings → About → Updates. It downloads and installs itself quietly.

💎

Cubelight identity

Blocky visuals, animated banner scenes (dawn → storm → snow), blue glow — a look all its own.

🛡️

Per-user, no admin

Installs for you without admin rights. Remove it any time from Apps & Features.
