What's new

  • Automatic translation for mod descriptions — mod descriptions are published in English; Cubelight now translates them in-app via MyMemory, caching every result on disk.
  • Languages — ar / es / fr / de / pt / tr / ru / zh / ja.
  • Removed the custom cursor overlay — the old custom cursor is gone; the desktop cursor is used everywhere again.

Upgrading from v1.0.2

Install this setup over v1.0.2 — settings, accounts and modpacks carry over. Or wait for v1.2.1 and update from inside the launcher.
